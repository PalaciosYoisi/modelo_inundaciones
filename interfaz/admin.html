    Actualizar el modelo

    El modelo aprende de los datos que ya están publicados. Al actualizarlo se entrena una versión nueva con todos esos datos y se compara con la que está en uso. La versión nueva no se usa hasta que usted decida. Puede tardar varios minutos. Conviene actualizar cuando ya haya confirmado varias semanas de datos nuevos: con pocos días, las diferencias suelen ser casualidad.

    Versiones del modelo

    Cada actualización deja una versión nueva. Aquí ve cuál está en uso y cuáles esperan una decisión. El puntaje del rojo va de 0 a 1 y mide qué tan bien se anticipan las crecidas (1 sería perfecto).
